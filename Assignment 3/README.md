# Mini Assignment 3 – Statistical Modeling & Survival Analysis

## Objective

Apply parametric and non-parametric statistical testing and survival modeling on TCGA-derived clinical and genomic datasets.

---

## Analysis Components

### Expression Differences (Male vs Female)
- Identified appropriate parametric test (independent t-test)
- Verified assumptions:
  - Normality
  - Homogeneity of variance
- Considered transformations if violated
- Evaluated non-parametric alternative (Mann–Whitney U)

---

### Relationship Between Age and miRNA Expression
- Assessed linear relationships via correlation analysis
- Checked assumptions:
  - Linearity
  - Normality
  - Homoscedasticity
- Used Spearman correlation when assumptions failed

---

###  Kaplan–Meier Survival Analysis
- Created binary high/low expression variable (median split)
- Performed KM survival analysis
- Conducted Log-Rank test
- Evaluated censoring assumptions
- Generated publication-quality survival curves

---

- Assumption validation
- Statistical decision-making
- Clinical variable integration
- Survival modeling
- Interpretation beyond p-values
